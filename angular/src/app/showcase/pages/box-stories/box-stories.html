Box

The base building block, inspired by Mantine's Box. Renders a block element (or any element via the l-box attribute) with style props for spacing (m/p shorthands on the xs–xl scale), size (w/h/maw…) and color (bg/c) — one-off layout tweaks without a stylesheet.

Style props: p="md" bg="var(--accent-bg)" c="var(--accent-dark)"

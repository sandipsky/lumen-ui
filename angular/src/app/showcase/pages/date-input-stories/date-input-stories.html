Date Input

An Ant Design-inspired date picker with a dual-calendar twist: the popup renders in either the Gregorian (AD) or Bikram Sambat (BS) system, switchable from a toggle in the panel footer. The model value is always a JS Date, whichever calendar is shown. Supports typing (YYYY-MM-DD, DD/MM/YYYY, …), month/year drill-down views, keyboard navigation, min/max bounds, a custom format, and Nepali-language rendering via lang="np".
